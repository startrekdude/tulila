Here you play the role of an _agent_, in one or more _networks_, asked to complete a _challenge_.

To do so, you will submit a Python program implementing your agent's behavior.

This tutorial series of challenges will teach you how to interact with the Tulila runtime environment. You will learn how to interact with other agents by sending and receiving messages and how to solve the challenge by submitting the solution string.

The first function you must learn how to use is `solve`:

```py
def solve(s):
    """Try to solve the challenge with the given solution string."""
    ...
```

This function is available to you in the runtime environment without importing anything. (To be completely clear: you are not required to _define_ `solve()`; you must, however, call it.)

The solution string for this challenge is `"i am ready to continue"`. Good luck!

_Tulila was designed and implemented by Sam Haskins in 2025 as her honours project. It was originally designed to be the perfect tool to deliver cryptography and computer security challenges to students._
